# LDR Based LED Control — Project Report

## 1. Introduction

This mini project demonstrates an automatic LED control system using an LDR and a transistor. The project was developed as a Course Mini Project in the Department of Electrical and Electronics Engineering.

## 2. Objective

To develop a simple automatic LED control circuit that responds to changes in surrounding light conditions.

## 3. Components

- 9 V Battery
- 100 kΩ Resistor
- BC547 Transistor
- LED
- LDR
- Breadboard
- Connecting wires

## 4. Working

The LDR senses the surrounding light condition and works with the transistor switching arrangement to control the LED.

### Observed operation

| Condition | LED |
|---|---|
| More surrounding light | OFF |
| Less surrounding light / Dark | ON |

## 5. Practical Implementation

The circuit was assembled on a breadboard using the listed components and tested under different light conditions.

## 6. Applications

The project demonstrates a basic concept for automatic and energy-efficient lighting control.
